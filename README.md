# QubitFold

**A tiny, test-driven quantum circuit peephole optimizer written in Python.**

QubitFold takes a quantum gate circuit, removes redundant operations, merges
adjacent-axis rotations (even across gates on disjoint wires), and verifies that
the resulting circuit implements the same *full unitary* up to global phase.

An AI-assisted educational portfolio project exploring quantum compilation
techniques. **Not affiliated with Xanadu or PennyLane.**

## Why this exists

Quantum circuit compilers transform gate programs into equivalent, often smaller
ones. Correctness must be verified: it is not sufficient to test only a single
input state. This project provides a simple compiler intermediate representation,
a rewrite pass, a NumPy reference simulator, randomized tests, and a CLI.

## What it does

- Supports `H`, `X`, `Y`, `Z`, `RX`, `RY`, `RZ`, `CNOT`, `CZ`, and `SWAP`.
- Cancels identical self-inverse gates, e.g. `H(0); H(0)`.
- Fuses same-axis rotations, e.g. `RZ(1, 0.2); RZ(1, 0.3)`.
- Recognizes independent gates on disjoint wires when simplifying.
- Checks matrix equivalence *up to global phase* for circuits of up to 6 qubits.
- Reports gate count, two-qubit gate count, and estimated parallel gate depth.
- Includes reproducible randomized semantic checks and continuous integration.

## Quick start

Requires Python 3.10 or newer.

```bash
python -m pip install -e '.[dev]'
pytest -q
python -m qubitfold examples/sample_circuit.json -o optimized.json
```

The CLI prints before/after gate metrics and a full-unitary equivalence check.

### Verified example

On November 13, 2026, the recovered project passed all **26 tests** locally on
Python 3.12 with NumPy 2.3.5. The supplied example changed from 10 gates / depth 6
to 3 gates / depth 2 (two-qubit gates: 3 to 1), with full-unitary equivalence up
to global phase confirmed. These numbers describe this small example, not a
general performance benchmark. The reproducible tests include 75 randomized
circuits across 2, 3 and 4 qubits with 30 gates each.

Input format:

```json
{
  "n_qubits": 2,
  "gates": [
    {"name": "H", "wires": [0]},
    {"name": "CNOT", "wires": [0, 1]},
    {"name": "RZ", "wires": [1], "theta": 1.5707963267948966}
  ]
}
```

`theta` values are in **radians**, and wire 0 is the most significant qubit.

## Implementation

- `qubitfold/core.py`: Immutable validated intermediate representation
- `qubitfold/optimize.py`: Conservative rewrite rules
- `qubitfold/simulate.py`: General 1–2-qubit operator application to n-qubit states
- `qubitfold/metrics.py`: Resource metrics
- `qubitfold/cli.py`: Command line interface
- `tests/`: Unit and randomized equivalence tests

## Limitations

This is a learning-scale project, not an industrial quantum compiler.
Compilation passes do not yet account for gate connectivity, noise, hardware
calibration, or scheduling duration. Statevector simulation scales exponentially;
full-matrix verification is deliberately capped at 6 qubits. Simplifications may
change **global phase**, which does not affect standard measurement outcomes.
There is no dependency on or direct integration with PennyLane yet.

## Suggested extensions

1. A PennyLane adapter, compared against PennyLane's `qml.matrix`.
2. Hardware-native basis gate decomposition and directed connectivity.
3. Graph-based circuit rewriting and cost-aware search.
4. Benchmarks on larger, structured circuits.
